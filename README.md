# Pujo Atlas Data Validator
> data base needs to be added separately

- clone the repo
  ```
  git clone https://github.com/leofossilis/pujo_atlas
  ```
- install the environment & activate
    ```
    conda env create -f pujo_atlas.yml
    conda activate pujo_atlas
    ```
- run the app
  ```
  streamlit  run validator.py
  ```
